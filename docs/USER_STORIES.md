# MIZAN — User Stories

Format: `As a <user>, I want <capability>, so that <benefit>.` Each story references its Functional Requirement ID(s).

## Authentication
- US-1: As a new user, I want to register with email and password, so that I can create my MIZAN account. (FR-AUTH-1)
- US-2: As a returning user, I want to log in quickly, so that I can check my finances. (FR-AUTH-2)
- US-3: As a security-conscious user, I want to unlock the app with biometrics, so that my financial data stays protected without typing a password every time. (FR-AUTH-4)
- US-4: As a user who forgot my password, I want to reset it via email, so that I regain access without losing my data. (FR-AUTH-3)

## Dashboard
- US-5: As a user, I want to see my total balance at a glance, so that I know where I stand financially today. (FR-DASH-1)
- US-6: As a user, I want to see my budget status on the dashboard, so that I know if I'm overspending before it's too late. (FR-DASH-3)
- US-7: As a user, I want to see upcoming bills on my dashboard, so that I don't get surprised by a due payment. (FR-DASH-4)
- US-8: As a user, I want to see my top AI insight on the dashboard, so that I get proactive value without having to ask. (FR-DASH-6)

## Transactions
- US-9: As a user, I want to log an expense in a few taps, so that tracking doesn't feel like a chore. (FR-TXN-2, FR-TXN-7)
- US-10: As a user, I want to log my salary, so that my income is reflected in my available balance. (FR-TXN-1)
- US-11: As a user, I want to record a transfer between accounts, so that my balances stay accurate. (FR-TXN-3)
- US-12: As a user, I want to add a recurring bill, so that I get reminded automatically instead of remembering manually. (FR-TXN-4)
- US-13: As a user, I want to set a savings goal, so that I have a concrete target to work toward. (FR-TXN-6)

## Budgets & Transfers
- US-14: As a user, I want to set a monthly budget per category, so that I can control discretionary spending. (FR-BUDGET-1)
- US-15: As a user, I want to be alerted when I'm close to my budget limit, so that I can course-correct before overspending. (FR-BUDGET-3)
- US-16: As a user, I want to view my transfer history, so that I can audit my money movement. (FR-BUDGET-4)

## Notifications
- US-17: As a user, I want a single place to see all my financial alerts, so that I don't miss anything important. (FR-NOTIF-2)
- US-18: As a user, I want to distinguish read from unread notifications, so that I can focus on what's new. (FR-NOTIF-2)

## AI Assistant
- US-19: As a user, I want to ask MIZAN's assistant plain-language questions about my money, so that I don't have to analyze spreadsheets myself. (FR-AI-1)
- US-20: As a user, I want the assistant's answers to be based on my real data, so that I can trust its guidance. (FR-AI-5)
- US-21: As a user, I want proactive spending pattern insights, so that I discover problems I wouldn't have thought to ask about. (FR-AI-2)

## Settings & Personalization
- US-22: As a user, I want to switch between light and dark mode, so that the app is comfortable at any time of day. (FR-SET-1)
- US-23: As an Arabic-speaking user, I want the entire app in Arabic with proper RTL layout, so that it feels native to me, not translated. (FR-SET-2)
